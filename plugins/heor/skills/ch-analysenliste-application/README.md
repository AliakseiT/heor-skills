# ch-analysenliste-application

Drafts a Swiss Analysenliste notification form (Meldeformular Analysenliste)
for a new laboratory analysis, submitted to the BAG/EAMGK-AL.

## When to use

- "Draft the Analysenliste application"
- "Swiss laboratory test reimbursement form"
- "List a new diagnostic assay in Switzerland"
- "Companion diagnostics listing"

## What it produces

`applications/ch/analysenliste/<lang>.md` — a complete 26-section notification
form in German (default) or French. Sections cover: contact, applicant type,
analysis designation, classification, technique, indications, tariff,
legal framework, quality assurance, performance data, scientific evidence.

## Templates

Official BAG Meldeformular templates (March 2025 version):
`references/templates/de.md` and `references/templates/fr.md`.
