# Documents

This directory holds user-supplied source documents for the SereniCBT
dossier. In a real dossier, these would include:

- CE certificate (MDR Class IIa)
- Instructions for Use (IFU)
- Device description / technical file
- Clinical Evaluation Report (CER)
- Study protocols and reports
- Regulatory correspondence

The demo dossier does not include actual documents. The skills that read
from this directory tolerate missing files and will note gaps.
